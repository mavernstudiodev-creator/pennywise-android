# Pennywise

**A Behavioural Approach to Student Budget Management**

Pennywise is a student-focused personal finance app concept designed to help college students understand spending patterns, manage budgets and build healthier financial habits.

## Android release

The Android APK is distributed through [GitHub Releases](https://github.com/mavernstudiodev-creator/pennywise-android/releases).

> Before installing an APK shared outside Google Play, verify that it came from the expected release and review any Play Protect warning. This repository does not certify APK safety.

## Product focus

- Income and expense tracking
- Student allowance and budget management
- Spending-pattern insights
- Savings goals
- Optional behavioural purchase reflections
- Adaptive light and dark appearance
- Offline-first personal finance management
